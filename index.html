Como ler este painel

  • Sem inferência individual. Os números são agregados oficiais por município; o painel não afirma que eleitores de um candidato migraram para outro entre turnos.
  • Denominador. “% válidos” é a fatia do candidato sobre todos os votos válidos do município naquele turno — todos os candidatos, não só os dois comparados.
  • Três medidas diferentes. Variação em votos = votos no 2º turno menos votos no 1º. Crescimento (%) = variação dividida pelos votos do candidato no 1º turno × 100. Variação em p.p. = participação no 2º turno menos participação no 1º.
  • Base zero. Quando o candidato teve 0 voto no 1º turno, o crescimento percentual é indefinido e aparece como “—”.
  • Abrangência. O exterior (ZZ) é excluído; o DF é mantido como unidade eleitoral do TSE. Municípios sem resultado oficial nos dois turnos ficam de fora do pareamento.
  • Apuração parcial. Municípios com apuração não finalizada em algum turno são contados no aviso acima da tabela.
  • Fonte. Divulgação oficial de resultados do TSE (dados baixados para a base local indicada no topo).
